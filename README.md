# Madhav Zanwar: portfolio

Static single-page site (`index.html`, no build step). Open the file in a browser or host it on any static host.

- `images/wall/`: photos for the draggable wall. Add a new `<figure class="photo">` in the `#board` block (or replace a `.slot`).
- Journey stops live in the `STOPS` array in the script; projects in `P`.
