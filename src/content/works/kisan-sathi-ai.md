## Overview

**Kisan Sathi** is an intelligent agricultural advisory application engineered for **Smart India Hackathon 2026**, delivering real-time crop disease diagnosis, localized meteorological forecasting, and soil health recommendations directly to Indian smallholder farmers through voice in regional languages.

### Key Capabilities
- **Visual Pest & Disease Detection:** Farmers snap a photo of damaged crop leaves; the computer vision pipeline identifies pathogens (fungal, bacterial, deficiency) with over 94% validated precision.
- **Vernacular Voice AI:** Native audio input and spoken audio guidance supporting Hindi, Marathi, Telugu, and English powered by low-latency speech pipelines.
- **Micro-Climate Advisory:** Ingests live satellite and ground telemetry to advise optimal irrigation and fertilizer scheduling.

### Technical Stack
- **AI Core:** Gemini 1.5 Flash Vision, Whisper Speech-to-Text
- **App Engine:** React Native / React Web, Tailwind CSS
- **Backend:** Node.js, Express, MongoDB Atlas, Redis Cache
