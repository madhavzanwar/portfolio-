## Overview

**Kisan Sathi** is an intelligent agricultural advisory application empowering Indian smallholder farmers with real-time leaf disease diagnosis via computer vision, automated voice assistance across regional Indian languages, and machine learning fertilizer recommendations.

### Key Capabilities
- **Visual Leaf Disease Diagnosis:** Farmers take a picture of damaged leaves; the computer vision model identifies pathogens (fungal, bacterial, blight) with over 94% validated precision.
- **Vernacular Voice AI:** Native audio input and spoken guidance supporting Hindi, Marathi, Telugu, and English powered by low-latency speech pipelines.
- **Weather & Irrigation Telemetry:** Ingests live satellite meteorological forecasts to recommend optimized irrigation intervals.

### Technical Stack
- **AI Core:** Gemini 1.5 Flash Vision, Whisper Speech-to-Text
- **App Engine:** React Web, Tailwind CSS, Vercel Edge Runtime
