## Overview

**LeadDesk Mini** is a sleek, hyper-performant mini-CRM platform built for independent consultants and small growth teams. It centralizes inbound lead capture, provides instant Kanban pipeline triage, and tracks conversion velocity through real-time telemetry dashboards.

### Key Capabilities
- **Relational Data Modeling:** Architected on Prisma ORM and PostgreSQL with strict referential integrity, automated migrations, and compound indexing.
- **Role-Based Authentication:** Secure JWT session management with multi-tenant workspace isolation.
- **Dynamic Kanban Triage:** Optimistic drag-and-drop state updates with automated sync and undo triggers.
- **Webhook Integrations:** Instant ingestion webhooks for Typeform, Calendly, and Zapier inbound events.

### Technical Stack
- **Framework:** Next.js 15 (App Router, Server Actions)
- **Database:** PostgreSQL on Supabase via Prisma ORM
- **UI & UX:** Tailwind CSS, Radix UI primitives, Lucide React
