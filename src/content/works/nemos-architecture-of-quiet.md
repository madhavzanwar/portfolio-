## Overview

**NEMOS** is an avant-garde digital sensory sanctuary built for the **Brand & Creative Builder Award '26**. Exploring the emotional threshold of silence and digital deceleration, NEMOS combines interactive typography, ambient spatial audio, and cinematic easing curves into a calm, focused web environment.

### Core Highlights
- **Sensory Interaction:** Custom soundscapes synchronized to scroll velocity and viewport proximity.
- **Micro-Interaction Choreography:** Gentle kinetic typography using fluid spring dampening and staggered reveals.
- **Responsive Architecture:** Deployed on Vercel with near-instant sub-second hydration and 60fps animations on mobile devices.

### Technical Stack
- **Framework:** React 18 with Vite
- **Styling:** Tailwind CSS with fluid typography clamping
- **Motion:** Framer Motion spring physics & layout projections
- **Audio Engine:** HTML5 Web Audio API with smooth gain ramping
