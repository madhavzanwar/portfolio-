## Overview

**Placement AI** is an end-to-end placement intelligence platform for college engineering students featuring automated resume parsing, placement readiness scoring, interactive mock interviews with behavioral and technical feedback, and personalized skill roadmaps.

### Key Capabilities
- **Automated Resume Parsing:** Analyzes student resumes against industry benchmark job descriptions, scoring keyword density, impact metrics, and formatting.
- **Adaptive Mock Interview Simulator:** Simulates real technical and HR interview rounds with dynamic follow-up questioning based on student responses.
- **Actionable Diagnostic Scorecards:** Provides quantitative breakdowns on technical correctness, communication clarity, and confidence metrics.

### Technical Stack
- **Backend:** Python, Flask, LangChain LLM evaluation chains
- **Frontend:** Responsive React dashboard with live audio waveform feedback
- **Hosting:** Render cloud deployment with persistent session states
