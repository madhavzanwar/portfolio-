## Overview

**Pulse Forge** is a real-time developer productivity and engineering velocity telemetry dashboard designed for high-performing engineering squads. It aggregates Git commits, build durations, test pass rates, and PR review latency into an intuitive mission-control center.

### Key Capabilities
- **Live Streamed Metrics:** WebSocket connections delivering sub-100ms updates on automated CI/CD pipeline states and code test coverage.
- **Sprint Burn-Down Velocity:** Predictive estimation of sprint completion dates using rolling historical velocity averages.
- **Micro-Interactions & Dark Mode:** Crafted with high-contrast UI design tokens, responsive data visualization charts, and accessible focus states.

### Technical Stack
- **Frontend:** React 18, TypeScript, Tailwind CSS, Lucide React
- **Data Engine:** WebSockets, Recharts, Server-Sent Events (SSE)
