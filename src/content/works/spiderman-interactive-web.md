## Overview

Created as a web design competition submission, the **Spider-Man Interactive Experience** delivers an electric comic-book aesthetic driven by tactile physics cursors, kinetic web-shooter transitions, and high-energy multi-page choreography.

### Core Highlights
- **Physics-Based Cursor:** Custom inertial cursor physics that trails mouse acceleration with dynamic tension and elastic retraction.
- **Dynamic Action Panels:** Asymmetric comic grid layouts that react to hover gestures with 3D card tilt and holographic foil effects.
- **Audio-Visual Feedback:** Interactive sound design on page switches, web snaps, and navigation triggers.

### Technical Stack
- **Frontend:** React 18, Vite, TypeScript
- **Motion:** Framer Motion gestures & transform pipelines
- **Styling:** Tailwind CSS with custom neon chromatic aberration filters
