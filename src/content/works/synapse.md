## Overview

**Synapse AI Tutor** is an intelligent personalized tutoring platform that adapts learning roadmaps to individual student pacing, performs automated code syntax evaluation, and visualizes knowledge mastery curves over time.

### Key Capabilities
- **Socratic Concept Exploration:** Guides students toward algorithmic breakthroughs through scaffolded questioning rather than merely regurgitating answers.
- **Dynamic Mastery Curves:** Computes real-time forgetting curves (Spaced Repetition) and schedules targeted concept re-testing.
- **Syntax & Logic Sandbox:** Embedded live code evaluation supporting Python, C++, and Java with instant runtime diagnostics.

### Technical Stack
- **Architecture:** FastAPI, Python 3.12, LangChain, React, Monaco Editor
